# MaintainerFlow public-demo candidate

This tiny synthetic project exists only to exercise PR risk, repository context, Check suggestions,
issue triage and release-note preview. It has no production dependency or real user data.

Run its tests with Python 3.12:

```powershell
python -m unittest discover -s tests
```

Follow `../README.md` before making this a separate public repository. Never copy MaintainerFlow App
credentials into this repository.
